# Pro App UX Principles

P0. Humans first. Remove anything that makes users think.
P1. One mental model: this is WhatsApp for business.
P2. One home: chats.
P3. Every tap must open a real chat, create a real action, or show a clear lock reason and next step.
P4. If a screen is empty or not wired end-to-end, hide it.
P5. No duplicate inbox concepts. Inbox is the chats list.
P6. Agents are employees inside chats, not a marketplace of cards.
P7. Reduce navigation. Fewer tabs, fewer options, fewer pages.

## Definition of "Real"

- Data comes from persistent storage.
- Actions call real backend endpoints.
- Status updates are posted in the same chat thread.
- No placeholder copy and no dead buttons.
