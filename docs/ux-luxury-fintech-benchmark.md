# Luxury-Fintech UX Benchmark (Reference)

This is a benchmark rubric to keep Bourse de l’Or aligned with **luxury fintech / exchange-grade** UX conventions.

## The Benchmark Bar

Users should feel:

- Calm
- In control
- Protected
- Confident
- One tap away from what matters

## Patterns To Match (Mobile)

### 1) “Shell + Modes” Architecture

- Stable shell (header + bottom nav)
- Modes are explicit and discoverable
- No hidden context switches

### 2) Thumb-Zone First

- Primary actions in the bottom zone
- Secondary actions never require top-left hunting
- Gestures work everywhere (swipe between primary surfaces)

### 3) Trading/Fintech Information Density

- Quantity/availability is first-class
- Price is always contextual (per g/kg/oz)
- Proximity is supportive and instant (map is one tap away)

### 4) Trust Signals Without Noise

- Verification badges are subtle but persistent
- Contracts, receipts, and audit trails are always one tap away
- Vault holdings show identifiers (unit IDs, lots, serials) in a readable way

### 5) Premium Visual Language

- Fewer elements, stronger hierarchy
- Large spacing where it matters, not everywhere
- Images are high-quality and varied (no obvious repetition)

## Anti-Patterns (Avoid)

- Full-screen modal traps without clear exit
- Floating buttons blocking CTAs
- Duplicate navigation items across top + bottom
- “Setup” screens that block core browsing (especially location)
