This folder holds product images used by the demo UI.

- `npm run images:generate` can populate realistic product photos via OpenAI Images (DALL·E).
- Keep filenames stable so seeded products keep working.

Using your attached images:
- Save your images into this folder and name them to match the targets below. The app will pick them up automatically.
- If a file already exists, `npm run images:generate` will skip it (so your own images won’t be overwritten).
