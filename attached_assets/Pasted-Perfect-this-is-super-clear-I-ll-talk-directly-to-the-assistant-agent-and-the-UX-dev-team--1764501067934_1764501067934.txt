## 3. Map UX: Navy Blue World + Vivid Product Clouds

**Design system:**

1. **Global color scheme:**

   * **Dominant UI color:** deep **navy blue** (headers, main controls, key buttons).
   * Backgrounds / basemap: **muted**, low-saturation:

     * Dark blues, greys, soft neutral tones.
   * No strong colors on the basemap itself — keep it calm.

2. **Product/category visuals:**

   * Each category has its own **vivid icon/image** that “pops” on the muted map.
   * Examples:

     * Bakery → golden-brown bread / baguette image.
     * Coffee → rich brown coffee cup or beans.
     * Vegetables → bright green/orange basket.
     * Metalwork → shiny metallic gate/door icon.
     * Gold → bright slab / ingot.

3. **Cloud effect when zoomed out:**

   * When the map zooms out:

     * Use **clustering**:

       * Food producers cluster → icon looks like a cloud of food.
       * Coffee cluster → bigger coffee icon.
       * Bakeries cluster → bread cloud.
   * The more dense the producers, the more visible the “cloud” of that category.

   This way, from far away, users see **clouds of products** over regions.
