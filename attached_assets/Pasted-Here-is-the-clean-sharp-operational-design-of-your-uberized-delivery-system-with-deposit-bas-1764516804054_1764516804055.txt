# ✅ **UBERIZED DELIVERY SYSTEM — CORE DESIGN**

**Goal:**
A global on-demand delivery network where *any delivery agent can activate themselves instantly* — **but only if their deposit/insurance covers the value of the order**.

This removes 95% of operational risk.

---

# 1️⃣ DELIVERY AGENT WALLET (DEPOSIT WALLET)

### **Every delivery agent has a “Deposit Wallet.”**

* When they sign up → they must **deposit money**.
* The deposit is **blocked**, not spendable.
* The system calculates in real time if their deposit is enough for the order.

### **Rule:**

> **Deposit ≥ order value**
> Else:
> **Agent cannot accept the order.**

### Examples:

* Deposit = 10,000 CFA → max order they can deliver = 10,000 CFA
* Deposit = 50,000 CFA → they can deliver higher-value orders
* Deposit = 0 → they cannot run deliveries

**This is identical to how Bolt drivers must maintain debt balance to accept trips.**

---

# 2️⃣ ORDER VALUE → AUTOMATIC ELIGIBILITY

When a new order appears:

* System checks each nearby delivery agent.
* Filters out anyone whose **deposit < order value**.
* Only eligible agents see the order pop-up.

### This eliminates:

* Theft
* Fraud
* Disputes
* Refund losses

The platform is ALWAYS covered before handing goods.

---

# 3️⃣ IF AN ORDER IS LOST OR DAMAGED

### The system automatically:

* Deducts the cost from the agent’s deposit.
* Sends the refund to the client.
* Notifies the agent.

If deposit becomes too low:

> **Account goes into "Low Balance" mode → cannot accept orders until topped up.**

---

# 4️⃣ OPTIONAL: MONTHLY INSURANCE PLAN

For more flexibility:

### **Insurance Tier System**

1. **Basic Tier (default)**

   * Must maintain 1:1 deposit
   * No insurance

2. **Silver Tier (small monthly fee)**

   * Deposit required: 50% of the order value
   * Insurance covers the other 50%

3. **Gold Tier (higher fee, for pros & companies)**

   * Deposit required: 0%
   * Insurance covers 100%

Insurance pools grow the more agents pay monthly.

This works especially for:

* Companies with fleets
* High-volume delivery agents

---

# 5️⃣ AGENT FLOW (IN APP)

### **1. Sign up → KYC → Pay Deposit**

* Mobile money / card / USSD
* Deposit instantly locked

### **2. Start Receiving Orders**

Only orders ≤ deposit appear on the map.

### **3. Delivery Workflow**

* Accept
* Scan QR code (just like rayOn delivery )
* Pick up
* Deliver
* Client scans QR to confirm

### **4. Deposit Behavior**

* Goes down only in case of loss/damage
* Topped up any time
* Can be withdrawn when the account is closed (minus liabilities)
