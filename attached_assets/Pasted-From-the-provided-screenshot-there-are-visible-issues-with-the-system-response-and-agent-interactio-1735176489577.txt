  3. If yes, the main agent creates additional agents dynamically.
  4. Agents discuss and execute the task in the chatroom.

**Code for Task Assignment**:
```python
@socketio.on('assign_task')
def assign_task(data):
    task_description = data['task']
    agent_id = data['agent_id']
    # Assign the task to the specified agent
    db.execute("INSERT INTO tasks (description, agent_id) VALUES (%s, %s)", (task_description, agent_id))
```
