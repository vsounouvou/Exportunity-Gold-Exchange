# 🔧 4. TASK ENGINE (THE TRUE WORK SYSTEM)

Agents execute tasks in **priority order** defined by orchestrator.

### 4.1 Task Types

1. **Scheduled Tasks**
   Daily scraping, daily posting, weekly reports, monthly analytics.

2. **Dependent Tasks**
   Lead scraping → qualification → outreach → follow-up
   Content creation → scheduling → posting → metrics analysis

3. **Event-Based Tasks**
   Triggered by:

   * WhatsApp message
   * Website chat widget
   * Form submission
   * Deal stage change
   * High-engagement social media post
   * Payment event

4. **Manual Tasks**
   Assigned by CEO (user).
   Orchestrator breaks complex tasks into subtasks & assigns agents.

### 4.2 Execution Rules

* Only **one department works at a time** unless tasks are independent
* Silence outside meetings
* No random chatter
* No overlapping long tasks
* Cooldowns
* Orchestrator posts summary reports
