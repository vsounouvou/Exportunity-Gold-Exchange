# Mobile UX Test Cases (Lightweight)

## 5-second rule

On first load, a user should understand:

1. “This is Bourse de l’Or”
2. “I can browse/search gold products”
3. “I can switch modes (Retail/Wholesale)”

## Core flows

### Location

- Deny GPS → still usable (search + manual location)
- Allow GPS → map centers correctly and results load

### Browse + sheet behavior

- Chip bar scroll does not conflict with map pan.
- Touch targets feel thumb-friendly (>= 44px).

### Purchase funnel (smoke)

- Add to cart
- Checkout steps progress
- Wallet balance visibility

### Offline

- Offline reload shows a friendly state (no crash, no blank page)
